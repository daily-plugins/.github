<h1 align="center">Daily Plugins</h1>

<p align="center">A collection of plugin repositories for everyday workflows.</p>

Tools for working with local knowledge and reviewing agent activity through MCP.

## Projects

- [Vault](https://github.com/daily-plugins/Vault) — Search, read, and edit Markdown in a selected local folder through MCP, with scoped instruction reviews.
- [Trace](https://github.com/daily-plugins/trace) — Review local Codex, Claude Code, and Antigravity sessions by time range, with message timestamps and source file/line evidence. Choose a registered environment and use the CLI, stdio MCP, or a private tunnel connection.

## In development

Trace's next steps are persistent incremental indexing for local logs and collection from remote services. Email and browser history collection are not yet implemented.
