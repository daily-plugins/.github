<h1 align="center">Daily Plugins</h1>

<p align="center">일상 작업을 위한 플러그인 저장소 모음.</p>

로컬 지식 자료를 다루고 에이전트 활동을 돌아볼 수 있는 MCP 도구를 만듭니다.

## 프로젝트

- [Vault](https://github.com/daily-plugins/Vault) — 선택한 로컬 폴더의 Markdown을 검색·읽기·편집하는 MCP 도구입니다. 적용 범위별 지침 검토를 지원합니다.
- [Trace](https://github.com/daily-plugins/trace) — 로컬 Codex·Claude Code·Antigravity 세션을 기간별로 조회하고, 메시지 시각과 원본 파일·줄 번호 근거를 제공합니다. 등록한 환경을 선택해 CLI, stdio MCP 또는 비공개 터널로 사용할 수 있습니다.

## 개발 예정

Trace는 다음 단계로 로컬 로그의 영속 인덱스·증분 수집과 원격 서비스 수집을 준비하고 있습니다. 이메일·브라우저 기록 수집은 아직 구현하지 않았습니다.
